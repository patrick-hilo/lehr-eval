# Managed central service instead of self-hosted server

The evaluation workflow requires central live state for teacher-controlled phases, student device synchronization, answer counting, re-entry, and QR-code invalidation. We will not rely on a purely static SharePoint HTML page or a self-operated server; instead, the first architecture direction is a simple managed central service with as little operational maintenance as possible. The currently known school environment includes Microsoft Teams and SharePoint; Power Platform, Dataverse, and Azure access must not be assumed unless confirmed later. An externally managed EU-hosted service is acceptable as a fallback if SharePoint/Microsoft 365 alone cannot support the live workflow without excessive complexity. Student devices are expected to be able to open an approved HTTPS web page in the browser without app installation or login.

If the selected managed solution does not support Microsoft 365 authentication, a separate system login is acceptable for the Administration only. Students remain anonymous browser users, and teachers use teacher QR plus PIN only for live execution, not for persistent result access.
